# Team Console updates

This small public repository holds only the newest release notice of Team Console:

- `latest.json` says which version is newest, its date, a one-line note and the installer's checksum.
- `latest.json.sig` is the signature of `latest.json`. A copy of Team Console accepts the notice only if the signature matches the publisher's public key.

There is no code here and no installer. The notice is shown as plain text; nothing in it is ever run.
